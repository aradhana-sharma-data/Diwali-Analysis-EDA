# Diwali-Analysis-EDA

## Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** of Diwali sales data using Python. The analysis examines customer purchasing behavior across different demographic and business-related categories.

## Dataset

The project works with the following data references:

- `Python_Diwali_Sales_Analysis`
- `Python_Diwali_Sales_Analysis 2`
- `Temp_data`

## Tools & Technologies

- **Python**
- **Pandas** — DataFrames and tabular data manipulation
- **NumPy** — Array operations
- **Matplotlib** — Data visualization
- **Seaborn** — Data visualization

## Data Cleaning

The analysis includes basic data-cleaning activities, including removing blank or unnecessary columns using the Pandas `drop()` function.

## Exploratory Data Analysis

The analysis explores sales and purchasing behavior based on:

### Gender
- Compared total purchase amount by gender.
- The analysis indicates that male buyers represented a significant portion of buyers and showed high purchasing power.

### Age Group
- Analyzed total purchase amount by age group.
- Examined purchasing behavior across different customer age groups.

### State
- Analyzed the number of orders across 10 states.
- Compared purchasing activity by geographic location.

### Marital Status
- Analyzed total purchase amounts based on marital status.
- Examined purchasing patterns across customer groups.

### Occupation
- Analyzed purchasing power based on occupation.
- The analysis indicates strong buyer representation from the **IT, healthcare, and aviation sectors**.

### Product Category
- Examined the product catalog and sales patterns.
- The analysis indicates that **food, clothing, and electronics** were among the most sold product categories.

## Key Insights

Based on the analysis and visualizations:

- Male buyers showed high purchasing power.
- Buyers working in **IT, healthcare, and aviation** represented important purchasing segments.
- **Food, clothing, and electronics** were among the most sold product categories.
- A key customer segment identified in the analysis was **married women aged 26–35 from Himachal Pradesh (HP) and Kerala**, particularly those working in IT, healthcare, and aviation, with interest in food, clothing, and electronics.

## Project Focus

The project demonstrates the use of Python for:

- Data cleaning
- Exploratory Data Analysis
- Customer segmentation
- Purchasing behavior analysis
- Sales pattern identification
- Data visualization

## Conclusion

This project demonstrates how exploratory data analysis can be used to understand customer demographics, purchasing power, geographic patterns, occupations, marital status, and product-category preferences from sales data.
